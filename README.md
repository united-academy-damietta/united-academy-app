# يونايتد أكاديمي - تطبيق الإدارة

تطبيق ويب لإدارة لاعبي الأكاديمية: الحضور، الاشتراكات، ورسائل الواتساب الجاهزة.

## التشغيل

```bash
npm install
npm start
```

ثم افتح من المتصفح: `http://localhost:3000`

ومن الموبايل على نفس شبكة الواي فاي: `http://<IP-اللابتوب>:3000`

## الشاشات

- **الرئيسية**: عدد اللاعبين، الاشتراكات السارية، المحصل الشهر ده، حضور النهاردة، والتجديدات المستنية.
- **اللاعبون**: بحث وإضافة وتعديل، وحالة الاشتراك لكل لاعب (نشط / فترة سماح / منتهي).
- **ملف اللاعب**: البيانات، سجل الاشتراكات، سجل الحضور، الرسائل.
- **الحضور**: تسجيل حاضر/غايب بلمسة، وزر "إغلاق اليوم" بيجهز رسائل الغياب.
- **الرسائل**: مسودات جاهزة (تأكيد اشتراك / تنبيه غياب / تذكير تجديد) وزر "فتح في واتساب" بيبعت بإيدك.
- **الإعدادات**: أيام التدريب، فترة السماح، أسعار افتراضية، وقوالب الرسائل.

## قواعد الأمان

- **مفيش إرسال تلقائي لأي رسالة.** كل الرسائل مسودات، والإرسال بيتم بضغطة منك عبر واتساب.
- قاعدة البيانات ملف واحد: `data/academy.db` - انسخه للنسخ الاحتياطي.

## البيانات التجريبية

أول تشغيل بيزرع 12 لاعب تجريبي. لمسحهم والبدء من الصفر: امسح ملف `data/academy.db` وشغّل التطبيق من جديد، أو عدّل اللاعبين من الشاشات مباشرة.

## التقنية

Node.js + Express + SQLite (better-sqlite3) + واجهة HTML/JS عربية RTL بدون أي خطوة بناء.
